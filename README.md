# tic--tac-toe
🎮 Tic-Tac-Toe Game

A simple and interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

🚀 Features

- Two-player Tic-Tac-Toe gameplay
- Interactive game board
- Detects winning combinations
- Detects draw/tie situations
- Displays the game result
- Reset/Restart game functionality
- Simple and responsive user interface

🛠️ Technologies Used

- HTML – Structure of the game
- CSS – Styling and layout
- JavaScript – Game logic, player turns, win and draw detection

📚 What I Learned

While building this project, I practiced:

- JavaScript DOM manipulation
- Event listeners
- Functions and conditional statements
- Arrays and game logic
- Handling user interactions
- Connecting JavaScript with HTML and CSS

▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
4. Start playing!
